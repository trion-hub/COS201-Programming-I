## Week 2: Development Environment and First Java Program

### Objective
To set up the Java development environment, write simple Java programs, compile them and run them successfully.

### Programs Created

**1. HelloWorld.java**

This program displays simple messages on the screen using Java output statements.

**2. StudentDetails.java**

This program collects a student's name, programme and level using the Scanner class and displays the information.

### Files
- `week02/HelloWorld.java`
- `week02/StudentDetails.java`

### How to Run

Open the terminal inside the `week02` folder.

To run HelloWorld:

```bash
javac HelloWorld.java
java HelloWorld
```

To run StudentDetails:

```bash
javac StudentDetails.java
java StudentDetails
```

### Skills Practised
- Setting up the Java development environment.
- Using `System.out.print()` and `System.out.println()`.

## Week 3: Variables, Data Types, Expressions and Input/Output

### Objectives
- Declare and initialize Java variables.
- Use appropriate data types.
- Perform arithmetic calculations.
- Read keyboard input using Scanner.
- Display program results.

### Programs Created

**1. SimpleCalculator.java**

This program accepts two numbers and calculates their sum, difference, product and quotient. It also checks that the second number is not zero before division.

**2. AverageCalculator.java**

This program accepts a student's name and three scores. It calculates and displays the total score and average.

**3. ItemCost.java**

This program accepts an item name, quantity and unit price. It calculates and displays the total cost of the items purchased.

### Files
- `week03/SimpleCalculator.java`
- `week03/AverageCalculator.java`
- `week03/ItemCost.java`

### How to Run

Open the terminal inside the `week03` folder.

To run SimpleCalculator:

```bash
javac SimpleCalculator.java
java SimpleCalculator
```

To run AverageCalculator:

```bash
javac AverageCalculator.java
java AverageCalculator
```

To run ItemCost:

```bash
javac ItemCost.java
java ItemCost
```

### Skills Practised
- Declaring and initializing variables.
- Using Java data types.
- Performing arithmetic operations.
- Collecting user input with Scanner.
- Displaying calculated results.
- Testing and correcting program errors.
